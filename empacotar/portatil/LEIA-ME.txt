Argos - o que está rodando de desenvolvimento (Docker, portas e processos)
Versão portátil: funciona sem instalar.

USAR
  1. Extraia este zip em qualquer lugar.
  2. Abra app\argos-app.exe.
  O ícone aparece perto do relógio. Ctrl+Alt+D abre o painel.

  A pasta "app" precisa ficar inteira (os .exe dependem da pasta _internal ao lado).
  Para o terminal, use app\argos.exe (ex: app\argos.exe rodar npm run dev).

O QUE A VERSÃO PORTÁTIL NÃO FAZ
  Não cria atalho no Menu Iniciar, não coloca o comando "argos" no PATH e não abre
  com o Windows. Para isso, use o instalador (Argos-Setup-<versão>.exe), na mesma
  página de onde este zip foi baixado.

REQUISITOS
  Windows 10 ou 11 com WebView2 (já vem no Windows 11 e junto com o Edge).
  Docker é opcional.

PRIMEIRO USO
  Por padrão, os projetos são as subpastas de "Área de Trabalho\projetos".
  Se for outro lugar, ajuste no painel: ícone de engrenagem > Pastas de projetos.

DADOS
  Configurações, sessões e logs ficam em %LOCALAPPDATA%\argos, mesmo na versão
  portátil. Para remover tudo, feche o app e apague essa pasta e a pasta extraída.
